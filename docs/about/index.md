# 关于

白天写企业级 ERP 的后端，晚上折腾自己的小工具。

这里放的东西分四类。

**文章**是想清楚一件事之后的长文，多数跟模型选型和 Agent 有关，因为这是这两年真正改变了我工作方式的部分。**笔记**是没成体系但踩过的坑，偏技术细节，目标是下次别再踩。**Todo** 是欠自己的账，分两本：待看的文章，待出稿的选题。**收藏**是读完还想再看第二遍的，不多，进得去的都有用。

写东西有几条自己的规矩。能查的数字就去查，查不到就直说查不到。自己做的实验样本小，就把样本小写出来。不为了凑结构硬分三点。
