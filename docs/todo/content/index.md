# 待出稿内容

这里放选题，不放链接。想写的东西，哪怕只有半个念头，也先记一行。

一条选题至少要写清楚「想说什么」——不是标题，是那个还没想明白但觉得值得说的点。只有标题的选题，两周后自己也看不懂当初想说什么。

<TodoContentList />

<p class="list-note">顺序是想法 → 在写 → 已发。没写完的按记下的时间排，先记的先写。记了超过 30 天没动的会被标出来——那是该删掉或者该动手的信号。写完的稿子挂上站内链接，会出现在「已发」里。</p>
